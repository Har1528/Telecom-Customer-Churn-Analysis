# Notebook

This folder contains the Jupyter Notebook used for the complete Telecom Customer Churn Analysis and Prediction project.

## Notebook

- **Customer_Churn_Analysis.ipynb**

## Contents

The notebook includes:

- Data loading
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Feature engineering
- Machine learning model development
- Model evaluation and comparison
- Feature importance analysis
- Business insights and recommendations

The notebook serves as the primary workflow documenting the complete analysis from raw data to predictive modeling.
